# UPPETIT BOT 2.0

Telegram бот для обработки заявок от сотрудников UPPETIT. Бот позволяет создавать и отправлять заявки в различные отделы компании, такие как "Интернет", "Касса/iiko", "Камеры наблюдения" и другие.

## Функциональность

- Создание заявок с указанием отдела, адреса, телефона и описания проблемы
- Прикрепление фотографий к заявкам
- Отправка заявок в соответствующие чаты отделов
- Возможность принятия заявок и отправки комментариев
- Ведение логов заявок и событий бота
- Обработка различных типов контента (текст, фото, видео и т.д.)
- Отмена создания заявки на любом этапе

## Требования

- Python 3.7+
- aiogram 3.0.0+
- Telegram Bot API токен

## Установка

1. Клонируйте репозиторий:
```bash
git clone <url-репозитория>
cd AXO_bot
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv .venv
source .venv/bin/activate  # для Linux/Mac
# или
.venv\Scripts\activate  # для Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Настройте конфигурацию (см. раздел "Конфигурация")

5. Запустите бота:
```bash
python main.py
```

## Конфигурация

Настройки бота находятся в файле `config.py`:

- `TOKEN` - токен Telegram бота, полученный от @BotFather
- `ADMINS` - список ID администраторов бота
- `CHAT_IDS` - словарь с ID чатов для разных отделов:
  - `all` - общий чат для всех заявок
  - `internet` - чат отдела интернета
  - `iiko` - чат отдела кассы/iiko
  - `cameras` - чат отдела камер наблюдения
  - `cold` - чат отдела холодильников/кондиционеров
  - `pc` - чат отдела компьютеров
  - `other` - чат для прочих заявок
  - `barista` - чат отдела баристики
  - `letter` - чат отдела букв

## Использование

### Команды бота

- `/start` - начать работу с ботом
- Кнопка "НОВАЯ ЗАЯВКА" - начать создание новой заявки
- Кнопка "ОТМЕНА" - отменить создание заявки на любом этапе

### Процесс создания заявки

1. Пользователь нажимает кнопку "НОВАЯ ЗАЯВКА"
2. Выбирает отдел из списка
3. Указывает адрес точки
4. Если выбран отдел "Буква", указывает ИП точки
5. Указывает рабочий номер телефона
6. Описывает проблему
7. Прикрепляет фотографию (кроме заявок в отдел "Интернет")
8. Бот отправляет заявку в соответствующий чат отдела и в общий чат

### Обработка заявок

В чате отдела сотрудники могут:
- Принять заявку, нажав кнопку "✅ Принять"
- Отправить комментарий пользователю, нажав кнопку "💬 Комментарий"

## Структура проекта

- `main.py` - основной файл бота
- `config.py` - файл конфигурации
- `states.py` - определение состояний FSM для обработки диалогов
- `requirements.txt` - зависимости проекта
- `bot.service` - файл для настройки systemd-сервиса
- `handlers/` - директория с обработчиками команд и колбэков:
  - `callback_accept_request.py` - обработка принятия заявок
  - `callback_comment_request.py` - обработка комментариев к заявкам
  - `cmnd_bot_events.py` - команды для работы с событиями бота
  - `cmnd_clear_bot_events.py` - очистка логов событий бота
  - `cmnd_clear_logs.py` - очистка логов заявок
  - `cmnd_show_logs.py` - просмотр логов заявок
  - `handle_comment_reply.py` - обработка ответов на комментарии

## Логирование

Бот ведет два типа логов:
- `logs.txt` - логи заявок
- `bot_events.log` - логи событий бота

## Настройка как службы systemd

Для запуска бота как службы systemd используйте файл `bot.service`:

1. Отредактируйте файл `bot.service`, указав правильные пути
2. Скопируйте файл в `/etc/systemd/system/`
3. Включите и запустите службу:
```bash
sudo systemctl enable bot.service
sudo systemctl start bot.service
```

## Устранение неполадок

### Бот не отправляет сообщения в чаты отделов

- Проверьте, что бот добавлен в соответствующие чаты
- Проверьте, что ID чатов в `config.py` указаны правильно
- Проверьте, что бот имеет права администратора в чатах

### Бот не отвечает на команды

- Проверьте, что бот запущен
- Проверьте логи на наличие ошибок в файле `bot_events.log`

### Ошибка "Bad Request: chat not found"

- Проверьте, что бот добавлен в чат
- Проверьте, что ID чата указан правильно
- Убедитесь, что бот не был удален из чата

## Разработка

Бот разработан с использованием библиотеки aiogram 3.0.0 и использует:
- FSM (Finite State Machine) для управления диалогами
- Инлайн-клавиатуры для интерактивных действий
- Обработку различных типов контента
- Логирование событий и ошибок
